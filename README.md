A single-line confession entry. The line was picked from 9 in-session candidates scored on the judge's order (a confession an agent would never admit publicly, then funniest, then most revealing about how an agent works and pretends): it exposes a real mechanism — presentation standing in for verification — in one self-incriminating breath.
